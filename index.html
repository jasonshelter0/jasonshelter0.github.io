A common thread / 02

A few guiding ideas.

These projects often start with a practical need: organizing notes, tracking a recurring task, or making information easier to find.

01

Start with real material

Notes, files, dates, and media are where the work begins. The interface should help you see them more clearly.

02

Describe state clearly

Show what is known, what is expected, and what still needs to be checked.

03

Leave room to explore

Small, open projects make space to test ideas, revise them, and share what is useful.

About / 03

About this site.

This is a home for my open-source projects and experiments. The subjects vary—from Obsidian and research workflows to calendars and media—but each project is an attempt to make a recurring task a little more understandable.
